# VScode-Codex配置

## 使用前提

在使用`Codex`联合`VScode`开发时，默认已经正确配置了`Codex Cli`。

## VScode内Codex使用

首先安装`Codex`插件。安装后，在界面右上角，聊天栏左侧将会出现`OpenAI`图标，点击即可打开`Codex`边栏以使用`Codex`。在聊天框中输入`/`，即可打开设置界面，或者直接输入指令以进行`Codex`设置。以下是常用设置：

`/model`：设置所使用的模型。也可以使用输入栏下方的列表直接选取。

`/ide`：设置是否读取`IDE`中的内容作为模型的上下文，将会提高项目消耗的`token`数，但是处理代码的能力增强。默认开启，可在输入栏下方点击禁用。
