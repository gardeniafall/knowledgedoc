# OriginPro图片格式常用设置

## Origin绘图中出现黑色“C”或者“demo”水印

激活问题，将本目录下的 OriginPrepare.exe 置于 Origin 的安装目录，先运行该文件后再打开 Origin

## Origion绘图默认字体设置

工具栏Preferences -> Options -> Text Fonts

## Origion绘图标签设置

双击已经绘制出的图像的标签，即可设置标签的大小、文字等

**标尺内置外置**：双击标签(X/Y Axis) -> Line and Ticks

**坐标轴标题颜色、字体与大小设置**：双击标签(X/Y Axis) -> Title

**坐标轴标签(数字)颜色、字体与大小设置**：双击标签(X/Y Axis) -> Tick Lables -> Format

## Origin绘图速度模式

**开启/关闭速度模式**：Format -> Layer -> Display/Speed -> Speed Mode ,选中/取消勾选

**调整速度模式参数**：修改后方数字

**直接关闭速度模式水印显示**：Preferences -> Options -> Graph ,右下角 Speed mode show watermark 选项取消勾选
